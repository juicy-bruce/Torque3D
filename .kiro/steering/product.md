# Torque3D Game Engine

Torque3D is an MIT-licensed open source 3D game engine originally developed by GarageGames. It's designed for creating 3D games and interactive applications with a focus on:

- Cross-platform development (Windows, Linux, macOS)
- Modular architecture with extensible components
- Built-in scripting language (TorqueScript)
- Advanced graphics rendering capabilities
- Physics simulation and collision detection
- Audio system integration
- Asset management and content pipeline

The engine follows a template-based project structure where new games are created from base templates, allowing developers to quickly bootstrap game projects while maintaining engine separation.

## Key Features
- C++17 codebase with CMake build system
- TorqueScript (.tscript) scripting language
- Modular component system
- Cross-platform rendering (DirectX, OpenGL)
- Built-in world editor and tools
- Asset pipeline for 3D models, textures, and audio
