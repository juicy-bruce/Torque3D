# Product Overview

This is a Torque3D-based game project called "shootertest" - a 3D first-person shooter game built on the Torque3D engine. The project includes:

- **Core Game**: FPS gameplay with team-based mechanics
- **Game Modes**: DeathMatch and TeamHQ (headquarters destruction) modes
- **Development Tools**: Full editor suite for level design, material editing, and asset management
- **Modular Architecture**: Component-based system with separate modules for core engine, gameplay, and tools

The project supports both dedicated server and client modes, with networking capabilities for multiplayer gameplay. It includes various gameplay systems like damage models, inventory, equipment, and team-based spawning.
